# Zayon Mobile UI

Use this skill for any UI work in Zayon.

- Follow [brand system](../../references/brand-system.md) for color, tone, and typography.
- Home screen = top insight rail + streaming assistant feed + inline property cards + anchored composer.
- Property screens should surface essential facts first, then AI summary, then actions.
- Voice is first-class input. Keep record state visible but quiet.
- Red is signal, not decoration.
- Avoid marketplace clutter, loud gradients, and generic chatbot layouts.
- Favor reusable primitives modeled after React Native Reusables patterns.
- Preserve calm spacing, concise copy, and smooth mobile motion.
